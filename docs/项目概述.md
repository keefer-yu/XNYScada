# 项目概述

XNY SCADA 面向单台新能源设备，覆盖组盘、拆盘、分档和 NG 挑选。业务差异尽量放在配置里：点位、流程、配方、界面布局和 MES 接口组成一份机型模板，现场切换机型时导入模板，而不是改程序。

两套界面功能对齐：登录、主监控、报警、设备与点位、通讯诊断、流程设计与监控、配方与分档、生产查询、MES、用户权限、审计、系统参数。WPF 提供画布式流程编辑器，WinForms 提供表格式流程编辑器，读写同一份流程 JSON。

## 技术栈

| 用途 | 组件 |
| --- | --- |
| 运行时 | .NET 8（界面工程为 `net8.0-windows`） |
| 宿主 | Microsoft.Extensions.Hosting |
| 界面状态 | CommunityToolkit.Mvvm |
| 数据库 | SqlSugar，默认 SQLite |
| PLC | HslCommunication，外加模拟驱动 |
| 表达式 | NCalcSync |
| 脚本节点 | Roslyn（`Microsoft.CodeAnalysis.CSharp.Scripting`） |
| 日志 | Serilog，控制台与按天滚动文件 |
| WPF 控件 | HandyControl |
| 测试 | xUnit |

包版本集中在 `Directory.Packages.props`。

configs/appsettings.json       数据库、安全、MES、HSL、日志
configs/machine-templates/     四个机型模板
src/                           类库与两个界面

运行后还会出现 `data/`（数据库）、`logs/`（日志）和 `plugins/`（扩展程序集）。这些目录已在 `.gitignore` 中排除，或由发布脚本创建。

## 内置机型

编码定义在 `MachineTypes`。

| 编码 | 名称 | 模板 |
| --- | --- | --- |
| `TrayAssembly` | 组盘机 | `configs/machine-templates/TrayAssembly.json` |
| `TrayDisassembly` | 拆盘机 | `configs/machine-templates/TrayDisassembly.json` |
| `Grading` | 分档机 | `configs/machine-templates/Grading.json` |
| `NgSorting` | NG 挑选机 | `configs/machine-templates/NgSorting.json` |

模板中的设备默认使用 `Simulator` 驱动，现场把 `DriverKey` 和连接参数改成实际 PLC 后再导入。

各机型的主流程：

- 组盘机：扫电芯条码，做 MES 校验，按托盘矩阵位置绑定，满盘后生成托盘号并上传。
- 拆盘机：扫托盘码，查出盘内电芯，逐位取料确认后解绑。
- 分档机：读取电压、内阻、容量，按当前配方的分档规则计算档位，把档位号写回 PLC。
- NG 挑选机：读取 NG 信息，映射到对应料盒并统计。
