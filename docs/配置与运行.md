# 配置与运行

配置文件随程序复制到输出目录。开发时改仓库里的 `configs/appsettings.json`，发布后改输出目录中的同名文件。

## appsettings.json

### Database

| 字段 | 含义 |
| --- | --- |
| `DbType` | SqlSugar 的数据库类型名，默认 `Sqlite`。也可填 `SqlServer`、`MySql`、`PostgreSQL`、`Oracle` |
| `ConnectionString` | 连接串。SQLite 默认 `Data Source=data/scada.db`，相对程序目录 |
| `RetentionMonths` | 生产记录保留月数，默认 12。设为 0 则不清理 |
| `LogSql` | 是否把 SQL 打到日志 |

SQLite 文件所在目录不存在时会自动创建。其他数据库会先尝试在服务器上建库，再按实体 CodeFirst 建表。

### Security

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `MinPasswordLength` | 6 | 最短密码 |
| `RequireDigit` / `RequireLetter` | true | 必须包含数字 / 字母 |
| `PasswordExpireDays` | 0 | 密码有效天数，0 表示不过期 |
| `MaxFailedAttempts` | 5 | 连续失败后锁定 |
| `LockMinutes` | 10 | 锁定时长 |
| `AutoLogoutMinutes` | 15 | 无操作自动登出。系统参数里的同名项会在启动时覆盖内存值 |
| `DefaultAdminPassword` | `Admin@123` | 仅在首次创建 `admin` 时使用 |
| `CardReaderPort` | null | 串口读卡器，如 `COM3`。为空时按 HID 键盘模拟读卡 |
| `CardReaderBaudRate` | 9600 | 串口波特率 |

### Mes

| 字段 | 含义 |
| --- | --- |
| `Enabled` | 总开关。关闭后流程里的 MES 节点按未调用处理，适合离线生产 |
| `CallbackPrefix` | 本机监听前缀，如 `http://+:8090/mes/`。为空则不监听 MES 回调 |
| `OutboxIntervalSeconds` | 发件箱补传间隔，默认 30 秒 |
| `OutboxMaxRetry` | 单条补传最大次数，默认 100 |

接口地址、请求模板和成功条件不在这里，而在 MES 配置或机型模板的 `MesInterfaces` 中。

### Hsl 与 Serilog

`Hsl:AuthorizationCode` 为 HslCommunication 商业授权码。日志默认级别 `Information`，`Microsoft` 与 `System` 为 `Warning`。文件日志在程序目录 `logs/scada-.log`，按天滚动，保留 60 个文件。

## 机型模板

一份模板是一个 JSON，根对象对应 `MachineTemplate`。

| 节点 | 内容 |
| --- | --- |
| `MachineType` / `Name` | 机型编码与显示名 |
| `Params` | 写入系统参数，如机台名、产线、工位 |
| `Layout` | 主界面是否显示托盘、档位、NG 料盒，以及关键点位、可手动触发的流程 |
| `Devices` | 设备、驱动参数、点位组、点位 |
| `Alarms` | 绑定 `设备.点位` 的位报警或限值报警 |
| `Recipes` | 配方、分档规则；`Activate: true` 的配方导入后成为当前配方 |
| `MesInterfaces` | HTTP 接口定义 |
| `Flows` | 流程定义，导入时生成新版本并发布 |

点位数值换算为 `原始值 × Scale + Offset`。字符串点位要填 `Length`。

库里还没有设备时，启动会自动导入一份模板：优先匹配系统参数 `MachineType`（种子值是 `Grading`），匹配不到就用目录里的第一个 JSON。之后在系统参数里可以再次导入，并选择是否清空现有设备。同编码流程会生成新版本并发布；同编码配方和 MES 接口按编码覆盖。手动导入需要 `System.ImportTemplate` 权限，首次自动导入不检查该权限。

首次建库还会写入这些系统参数（已存在的键不会覆盖）：

| 键 | 种子值 | 含义 |
| --- | --- | --- |
| `MachineType` | `Grading` | 当前机型编码 |
| `MachineName` | `分档机-01` | 设备名称 |
| `Station` | `ST01` | 工位号 |
| `IdealCycleSeconds` | `2` | 理想节拍，用于 OEE |
| `LayoutJson` | `{}` | 主界面布局 |
| `AutoLogoutMinutes` | `15` | 无操作自动登出分钟数，0 表示不登出 |

`Layout` 字段：

| 字段 | 含义 |
| --- | --- |
| `ShowTray` / `TrayRows` / `TrayCols` | 托盘矩阵，默认 4 行 6 列 |
| `ShowBins` / `BinCount` | 档位箱，默认 8 |
| `ShowNg` / `NgBoxCount` | NG 料盒，默认 4 |
| `KeyTags` | 主监控要显示的点位全名 |
| `ManualFlows` | 允许操作员手动触发的流程编码 |

## 本地运行与发布

```powershell
dotnet run --project src/XNY.Scada.Wpf
dotnet run --project src/XNY.Scada.WinForms
dotnet test tests/XNY.Scada.Tests
```

WPF 与 WinForms 使用同一个互斥量 `Global\XNY.Scada.SingleInstance`，避免两套界面同时占用 PLC。

`build/publish.ps1` 默认先跑测试，再以 `win-x64`、非自包含方式发布两个界面，并在 `artifacts` 下生成 zip。常用参数：

| 参数 | 作用 |
| --- | --- |
| `-Ui Wpf` 或 `-Ui WinForms` | 只发布一个界面 |
| `-SelfContained` | 携带 .NET 运行时 |
| `-SkipTests` | 跳过测试 |
| `-Installer` | 调用 Inno Setup 6 生成安装包 |
| `-Configuration` / `-Runtime` / `-Output` | 配置、RID、输出目录 |

发布目录会附带空的 `plugins`、`data`、`logs`，以及 `plugins/README.txt`。
