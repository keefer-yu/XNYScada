# 架构与模块

界面只负责呈现。ViewModel、用例服务、流程引擎、设备运行时和权限都在类库中，WPF 与 WinForms 通过依赖注入接上各自的对话框、调度器和窗口。

```
WPF / WinForms
    └── XNY.Scada.Presentation     ViewModel、导航与对话框抽象
            └── XNY.Scada.Application
                    ├── Domain          实体、枚举、表达式
                    ├── Flow            流程定义与执行
                    ├── Security        登录、RBAC、审计
                    ├── Data            SqlSugar
                    ├── Device.*        驱动抽象、HSL、轮询运行时
                    └── Mes             HTTP 适配与离线补传
```

`ScadaHost.AddScadaCore` 注册与界面无关的服务。两个 `Program` / `App` 再调用 `AddScadaPresentation`，并分别注册 `IUiDispatcher` 与 `IDialogService`。

## 工程

| 工程 | 职责 |
| --- | --- |
| `XNY.Scada.Domain` | 实体、枚举、`ScadaExpression`、业务服务接口 |
| `XNY.Scada.Data` | 连接、CodeFirst 建表、按月保留清理 |
| `XNY.Scada.Device.Abstractions` | `IPlcDriver`、点位定义、读写结果 |
| `XNY.Scada.Device.Hsl` | 西门子、三菱、欧姆龙、汇川、Modbus TCP |
| `XNY.Scada.Device.Runtime` | 插件加载、模拟驱动、通道轮询、断线重连、报警 |
| `XNY.Scada.Flow` | 流程 JSON、节点注册、执行器、调试 |
| `XNY.Scada.Security` | 用户、角色、权限、刷卡、空闲登出、审计 |
| `XNY.Scada.Mes` | 按接口配置发 HTTP，失败可进发件箱 |
| `XNY.Scada.Application` | 宿主、模板导入、配方、托盘、生产查询 |
| `XNY.Scada.Presentation` | 两套界面共用的 ViewModel |
| `XNY.Scada.Wpf` | WPF 壳与图形流程编辑器 |
| `XNY.Scada.WinForms` | WinForms 壳与表格式流程编辑器 |

## 启动顺序

`ScadaRuntimeService` 作为托管服务，按下面的顺序拉起运行时。启动界面订阅 `StartupProgress` 显示当前步骤。

1. 初始化数据库并建表。
2. 把代码里的 `[Permission]` 同步到权限表，补齐内置角色；没有 `admin` 时创建超级管理员。
3. 加载系统参数，并按 `AutoLogoutMinutes` 设置空闲登出。
4. 若库中还没有任何设备，按系统参数 `MachineType` 导入一份机型模板。默认机型是 `Grading`；对不上时使用模板目录中的第一个文件。
5. 加载当前配方。
6. 启动设备通讯和报警监视。
7. 重载 MES 接口。
8. 启动流程引擎。
9. 按 `RetentionMonths` 清理过期生产数据。清理失败只记警告，不阻止进入主界面。

停止时先停流程引擎，再停设备通讯。

`ScadaHostOptions` 可以关掉自动导入模板（`AutoImportTemplate`）或流程引擎（`StartFlowEngine`），并指定插件目录，默认是程序目录下的 `plugins`。

## 设备驱动

驱动实现 `IPlcDriver`，类上标注 `[PlcDriver]`。连接参数用 `[DriverOption]` 声明，界面按声明生成表单。

| DriverKey | 说明 | 默认端口 |
| --- | --- | --- |
| `Simulator` | 内存模拟，地址为任意字符串，如 `D100`、`M0` | 无 |
| `Siemens.S7` | S7-200 / 200Smart / 300 / 400 / 1200 / 1500 | 102 |
| `Mitsubishi.MC` | 3E 二进制、3E ASCII、A1E | 6000 |
| `Omron.FinsTcp` | FINS TCP，另有目标单元号 DA2 | 9600 |
| `Omron.Cip` | NJ/NX，地址使用变量名 | 44818 |
| `Inovance.Tcp` | H3U / H5U / AM，走 Modbus TCP | 502 |
| `Modbus.Tcp` | 通用 Modbus TCP | 502 |

西门子 S300 默认槽号为 2，其余 S7 型号默认机架号和槽号为 0。HslCommunication 未填写授权码时，部分功能有 8 小时限制，授权码写在 `Hsl:AuthorizationCode`。

每台设备一个通讯通道，按点位组的 `ScanIntervalMs` 批量读取。断线后通道自行重连。点位值变化通过 `TagChanged` 通知流程引擎和界面。点位全名是 `设备名.点位名`，例如 `PLC1.CellCode`。

把带 `[PlcDriver]` 或 `[FlowNode]` 的程序集放到 `plugins`，重启后由 `PluginLoader` 加载。

## 表达式

`ScadaExpression` 基于 NCalc，用在流程条件、分档规则、MES 成功判定和请求模板中。

- 直接写变量：`Voltage > 3.2`。名称含特殊字符时用 `[Dev1.Value]`。
- 占位符：`{Tag:PLC1.BinNo}`、`{Recipe:MaxIR}`、`{Var:BinNo}`、`{Global:Count}`。
- 文本模板使用 `${name}`，只替换、不计算。MES 请求体用这种写法。
- 扩展函数：`len`、`contains`、`startsWith`、`endsWith`、`substr`、`regex`、`concat`、`isEmpty`、`toNumber`、`toString`、`now`、`format`。
