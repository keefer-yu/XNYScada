# 数据与权限

实体除生产日表外都继承 `EntityBase`，包含自增 `Id`、`CreatedAt`、`UpdatedAt`。表由 SqlSugar CodeFirst 在启动时创建。

## 数据表

| 表 | 实体 | 内容 |
| --- | --- | --- |
| `sys_user` / `sys_role` | 用户、角色 | 账号、密码哈希、角色级别、是否内置 |
| `sys_permission` | 权限点 | 启动时与代码中的 `[Permission]` 对齐，代码里已删除的权限会从表中移除 |
| `sys_user_role` / `sys_role_permission` | 关联 | 用户角色、角色权限 |
| `sys_role_data_scope` | 数据范围 | 未配置某类范围时视为可访问全部 |
| `sys_audit_log` | 审计 | 登录、改参、写 PLC、发布流程、切换配方等 |
| `sys_param` | 系统参数 | 键值，含界面布局和机台参数 |
| `dev_device` / `dev_tag_group` / `dev_tag` | 设备与点位 | 驱动、扫描周期、地址、缩放 |
| `dev_alarm_def` / `dev_alarm_record` | 报警 | 规则与历史、确认信息 |
| `flow_definition` / `flow_version` | 流程 | 定义头与各版本 JSON |
| `flow_instance_log` | 流程日志 | 每次运行的状态、耗时和错误 |
| `prd_recipe` / `prd_grading_rule` | 配方 | 参数与分档规则 |
| `prd_tray` / `prd_tray_cell` | 托盘 | 托盘状态与电芯绑定 |
| `prd_cell_record_{yyyyMMdd}` | 生产记录 | 按日分表 |
| `prd_ng_record_{yyyyMMdd}` | NG 记录 | 按日分表 |
| `mes_interface` | MES 接口 | URL、方法、请求模板、响应映射、成功表达式、超时与重试 |
| `mes_call_log` | 调用日志 | 每次调用的结果与耗时 |
| `mes_outbox` | 发件箱 | 断网补传。状态为 `Pending`、`Sent`、`Failed` |

`Database:RetentionMonths` 控制日表保留时长。

## 登录

默认账号 `admin`，角色为超级管理员。密码在首次建库时取 `Security:DefaultAdminPassword`。该用户已存在时不会重置密码。

密码使用 PBKDF2 加盐存储。连续失败达到 `MaxFailedAttempts` 后锁定 `LockMinutes` 分钟。刷卡登录支持串口读卡器；未配置端口时按 HID 键盘输入处理。空闲超过 `AutoLogoutMinutes` 自动登出。

关键操作可要求再次验证身份，结果写入审计表。审计动作包括登录成败、改密、参数、设备、手动写 PLC、流程保存与发布、配方变更/审批/切换、用户与角色、MES、模板导入、报警确认和生产操作。

## 角色

内置角色只在数据库中不存在时创建，创建后不随程序升级改写其权限。超级管理员在 `PermissionService` 中直接放行，不依赖权限行。管理员拿到除 `Flow.Script` 以外的全部权限。级别用于限制一个用户能分配的角色：不能分配不低于自己最高级别的角色，超级管理员除外。

| 编码 | 名称 | 级别 | 能力概要 |
| --- | --- | --- | --- |
| `Operator` | 操作员 | 10 | 主监控、报警、生产；确认报警、启停、手动触发流程 |
| `Technician` | 技术员 | 20 | 另含诊断、流程监控、配方；清零、导出、托盘手动绑定、切换配方、手动写 PLC |
| `Engineer` | 工程师 | 30 | 另含设备、流程设计、MES、系统参数、审计；可改设备、重载通讯、编辑和调试流程、编辑配方、配置并测试 MES。不含发布流程、审批配方、脚本节点和导入模板 |
| `Admin` | 管理员 | 40 | 除脚本节点外的全部权限 |
| `SuperAdmin` | 超级管理员 | 100 | 跳过权限点检查，内置不可删除 |

## 权限点

权限由 `[Permission]` 标在 `Permissions` 的常量上，启动时写入 `sys_permission`。界面命令执行前调用 `IPermissionService.Demand`。

| 分类 | 编码 |
| --- | --- |
| 菜单 | `Menu.Dashboard`、`Menu.Alarm`、`Menu.Device`、`Menu.Diagnostics`、`Menu.FlowDesigner`、`Menu.FlowMonitor`、`Menu.Recipe`、`Menu.Production`、`Menu.Mes`、`Menu.User`、`Menu.Audit`、`Menu.System` |
| 生产 | `Production.Start`、`Production.ResetCounter`、`Production.ManualTrigger`、`Production.Export`、`Production.TrayManual` |
| 报警 | `Alarm.Acknowledge`、`Alarm.Configure` |
| 设备 | `Device.Edit`、`Device.ManualWrite`、`Device.Reload` |
| 流程 | `Flow.Edit`、`Flow.Publish`、`Flow.Script`、`Flow.Debug`、`Flow.Control` |
| 配方 | `Recipe.Edit`、`Recipe.Approve`、`Recipe.Switch` |
| MES | `Mes.Edit`、`Mes.Test` |
| 用户 | `User.Manage`、`User.ManageRole`、`User.ResetPassword` |
| 系统 | `System.Edit`、`System.ImportTemplate` |

数据范围按角色配置。某类范围一条都没有时，该类数据全部可访问；配置了范围后，只允许列出的值，`*` 表示该类全部。

## 配方与 MES

配方状态为草稿、待审批、已审批、已归档。只有已审批配方可以投入生产。编辑已审批配方会升版本并清除审批信息。模板导入的配方直接记为已审批，审批人写为 `template`。

分档规则按 `Priority` 从小到大匹配，先命中的规则生效。规则可以是字段区间，也可以是表达式，并可以标记为 NG、指定料盒容量和 NG 代码。

一条 MES 接口包含 URL、HTTP 方法、请求头、请求体模板、响应字段映射、成功判定表达式、超时和重试次数。适合补传的上传类接口在断网时进入 `mes_outbox`，由后台按间隔重试。调试调用走 `TestAsync`，不写发件箱。
